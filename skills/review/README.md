# Review Skills

Review skills govern product runtime, debugging, architecture, and verification
lenses that are not tied to one implementation stack.

Current skills:

| Skill | Role |
| --- | --- |
| `product-runtime-review` | Review user-facing runtime/product correctness. |
| `systematic-debugging` | Diagnose bugs and regressions with repro-first discipline. |
| `architecture` | Make and record architectural decisions. |
| `visual-modeling` | Produce Accelerate-grade structural diagrams for ERDs, sequences, state machines, journeys, agents, and trust boundaries. |
| `requesting-code-review` | Pre-commit verification, static scan, reviewer pass, and bounded auto-fix loop. |
| `code-audit` | P0-P3 security, architecture, maintainability, docs, and quality-gate audit. |
| `test-engineering` | Design risk-based suites, negative and non-functional cases, and independent regression proof. |
| `source-verification` | Reconcile claims with versioned authoritative sources, freshness, corroboration, and uncertainty. |
| `solution-minimalism` | Select the smallest sufficient post-spec/post-green solution without weakening safeguards or proof. |
| `web-performance-review` | Separate static opportunities from source-labelled measured web-performance evidence. |
