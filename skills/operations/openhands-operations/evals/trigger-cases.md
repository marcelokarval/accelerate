# OpenHands Operations Trigger Cases

## should trigger

- prompt: Restart Agent Canvas safely and prove the open-design MCP is healthy.
  expected: openhands-operations
- prompt: Diagnose why a governed skill is absent from a fresh OpenHands session.
  expected: openhands-operations
- prompt: Audit whether OpenHands child bindings are actually callable.
  expected: openhands-operations

## should not trigger

- prompt: Refactor application code from an OpenHands conversation.
  expected: no-trigger
- prompt: Change a DSH Agent Preset.
  expected: no-trigger
