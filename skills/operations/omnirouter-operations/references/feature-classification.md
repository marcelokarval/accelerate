# OmniRoute Feature Classification

## Proven Core — Keep

- OpenAI-compatible gateway and selected protocol adapters.
- Provider connections across API key, OAuth, web and CLI-derived surfaces.
- API keys per consumer.
- aliases/Combos with explicit order and fallback.
- model/account/provider failure separation.
- quota views, health, request/proxy logs, costs and runtime monitoring.
- pricing registry with explicit coverage gaps.

## Situational — Enable Only for a Named Case

- Webhooks for signed operational alerts.
- outbound proxy and per-connection proxy.
- Embedded Services as a temporary bridge.
- Traffic Inspector HTTP proxy.
- Headroom for homogeneous tabular JSON under an explicit request contract.
- Context Editing only for its supported provider/transport.
- provider quota preflight and budget enforcement after thresholds are authorized.

## Experimental, Unproved or Beta — Default Off

- Quota Sharing.
- Discovery scans.
- aggressive/ultra/relevance/LLMLingua/OmniGlyph compression.
- generic RTK/Caveman/Lite as global defaults.
- output styles for operational responses.
- Chaos/MoA runtime features.
- Cloud Agents and ACP Agents where the page only loads/detects.
- AgentSkills claims without API/CLI coverage.

## Conflicts with Hermes Ownership — Keep Off

- OmniRoute memory for Hermes conversations.
- Conductor/fleet councils and agent task ownership.
- custom system prompt injected into every model request.
- automatic Combo promotion that bypasses governed alias review.
- OmniRoute MCP/A2A as generic agent authority.

## Security/Forensic — Available but Not Ambient

- AgentBridge and TLS MITM.
- system-wide proxy.
- custom host/DNS interception.
- request replay.
- HAR export.
- full database export/import.

Traffic Inspector's explicit HTTP proxy is allowed in the internal solo-developer environment when redaction is enabled; the invasive modes remain separately gated.

## Product-Sprawl Noise

Community profile, leaderboard, token balances, achievements, referrals, rewards and marketplace do not contribute to the gateway acceptance denominator. Hide or ignore them.

## Maturity Labels

Use exact labels:

- `route-present`: UI/API path exists;
- `configured`: state exists;
- `healthy`: live owner reports healthy;
- `transport-proved`: request succeeds;
- `semantic-proved`: output/invariants pass;
- `fallback-proved`: intended failover observed;
- `production-qualified`: full frozen denominator passes.

Never upgrade `route-present` directly to `works`.
