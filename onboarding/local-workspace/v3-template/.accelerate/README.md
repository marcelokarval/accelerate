# Accelerate V3 Local Overlay

This directory is the V3 project-local overlay template. It stores only local
declarations, digest-bound pointers, and D01-owned generated execution state.
It does not copy skills or core doctrine, select a provider, or become a
workflow or planning authority.

Read `onboarding/local-workspace/v3-workspace-contract.md` before materializing
or consuming this tree. V2 remains a separate, supported template.
