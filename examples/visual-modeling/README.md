# Visual Modeling Examples

These examples provide copyable Accelerate-grade ASCII visual models. They are
not project-specific truth; they demonstrate shape, callouts, binding, and
residual handling for common diagram families.

## Index

| Example | Diagram family |
| --- | --- |
| `erd-lead-domain.md` | ERD / persisted data model |
| `orm-lifecycle-django-service-inertia.md` | ORM lifecycle |
| `class-module-service-boundary.md` | Class/module/function relationship |
| `sequence-stripe-webhook.md` | Sequence diagram |
| `state-machine-lead-lifecycle.md` | State machine |
| `swimlane-lead-journey.md` | Swimlane / journey |
| `agent-communication-proof-lane.md` | Agent communication topology |
| `c4-next-adonis-container.md` | C4 / architecture topology |
| `deployment-next-adonis-postgres.md` | Deployment/runtime topology |
| `queue-retry-dlq.md` | Queue/retry/DLQ topology |
| `trust-boundary-upload.md` | Trust boundary / dataflow |
| `governance-issue-topology.md` | Governance / issue / proof topology |

Every example should include source truth, artifact, callouts, binding, and
residuals so examples do not degrade into decorative ASCII.
