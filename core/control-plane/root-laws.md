# Entry authority — 1.x

Accelerate owns intent, initial preparation, risk screening and routing. It owns
only the direct conversational/trivial route through completion. Once work is
accepted by ASDS, ASDS owns planning through delivery and then releases it. The harness retains
execution and permission authority; user and project instructions remain binding.

No fixed staffing, issue bootstrap, project directory, review stack or root
closure ceremony is required merely by activating Accelerate. Technical skills
cannot recursively activate the old workflow. Use `../asds-integration.md` and
`../../SKILL.md`; old root laws are preserved in Git history.
