Status: `proposed`
Catalog: `planning/executive/accelerate-contract-v1-task-catalog.md`

Rule: a checked box without fresh, revision-bound evidence is not proof.

## Proof Record

Every row records `pass|fail|blocked|not-applicable`, exact command, UTC time, source revision, evidence locator, reviewer, and notes. `not-applicable` requires a named authority and rationale. Changes to an authority, denominator, schema, dependency, contract, matrix, validator, evidence ledger, generated file, fixture, or reviewed subject invalidate affected proof.

## Absolute Closure Blockers

- Any unresolved authority, SDD/wave-plan conflict, JSON Schema dependency decision, class/mode mapping, P0 task, or wave capability.
- Any denominator drift, hidden target, uncovered blocker, or coverage below its wave threshold.
- Any generated/user-home authority, reverse sync, provider coupling, path escape, secret/private leak, or unexplained dirty/staged path.
