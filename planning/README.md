# Optional planning resources

In Accelerate 1.x, ASDS owns planning for accepted work. This directory contains
reusable templates, validators and historical v0 planning artifacts. It is not a
second planning authority. ASDS may select a relevant template without activating
the previous Accelerate orchestration procedure or duplicating task state.

Existing project artifacts remain untouched. Classification never initializes
`.accelerate/` or `openspec/`, selects a tracker or creates an issue. Project and
user requirements still apply to the actual task.
