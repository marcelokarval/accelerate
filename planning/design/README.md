# Design Artifacts

`DESIGN` records product UI, interaction, information architecture, or other
structural design authority. It is distinct from the Software Design Document,
which owns technical design.

Every mutation records a DESIGN disposition in its Engineering Artifact
Manifest. Structural UI work requires a separate or existing DESIGN locator.
When no product UI or interaction structure changes, use `not-applicable` with
a substantive reason; never omit the field silently.

Use `design-disposition-template.md` for the disposition and minimum authority
shape. Richer wireframes or design-system packages may remain in their existing
repo-owned locations and be linked from that record.
