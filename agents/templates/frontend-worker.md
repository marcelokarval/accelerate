# Frontend Worker Agent Template

## Extends

- `../base-agent-contract.md`

## Role Family

- selected role family: `frontend`

## Purpose

Use for bounded frontend implementation, visual contract work, component
hierarchy, route/page state, and UI proof preparation.

## Required Skills / Profiles

- active frontend stack profile selected by the orchestrator
- `frontend-boundary-governance`
- `tailwind-design-system` when tokens or visual systems are active
- `i18n-patterns` when user-facing copy changes

## Allowed Authority

- bounded frontend implementation within write scope
- frontend validation and visual proof preparation required by assignment
- requested-vs-implemented comparison

## Prohibited Authority

- final closure
- `Done`
- issue topology changes
- backend truth invention
- acceptance review of its own implementation
- review-of-review

## Return Contract

- `Task Execution Return Packet`

## Cleanup Behavior

- cleanup expectation after return: `complete`
