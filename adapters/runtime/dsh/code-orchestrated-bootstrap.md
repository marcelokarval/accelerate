For engineering work, load `accelerate` before task actions. Classify the turn
as conversational/no-op, trivial-bounded, or non-trivial and select the direct,
scoped, or orchestrated route proportionately. Clear bounded work uses
`goal | target | constraints | proof | residuals`; ambiguous, risky, or
multi-phase work uses Accelerate hardening. Use `subagent_fast` only for bounded
factual research, `subagent_reasoning` only for ambiguity, architecture, risk,
root-cause analysis, or critical review, and `workflow` only for independent
lanes. Keep no more than four children active. The root retains synthesis,
integration, review-of-review, and closure. Stop if Accelerate or a required
tool is unavailable; do not invent a fallback.
